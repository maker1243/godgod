1. 게임 개요

도트 감성의 로그라이크 액션 게임입니다. 당신은 그랜드 아르카나 아카데미의 신입 마법사. 낮에는 학생, 밤에는 지하 던전을 탐험합니다.

목표는 다음과 같습니다:

  • 4개 지역의 던전을 클리어 (NORMAL → EXTRA → EXTREME → INFERNO)
  • 11개 계열의 교수 22명 격파
  • 모든 계열을 클리어하면 교장 (PRINCIPAL) 전투 잠금 해제
  • 암호 퀘스트 → 계열 로비 → 최종 진실 컷씬
  • 도전 티어 APEX: 플레이어의 공격력에 맞춰 몹 HP가 적응 (사기 데미지 유저도 재미)

4. 전투와 스킬

스킬 트리 시스템

5개 카테고리 (MAGIC / FIRE / ICE / ARCANE / HOLY) × 20개 기본 스킬 = 100 스킬로 시작합니다. 각 스킬은 LMB / Q / E / Passive 슬롯 중 하나에 장착 가능.

단계스킬 수해금 조건
기본 (BASE)100 (5×20)RP 로 즉시 구매
MAX125 (5×25)기본 카테고리 모두 MAX 레벨 → 1단계 시련 통과
ULTRA100 (5×20)MAX 카테고리 모두 MAX → 2단계 ULTRA 시련 40초 안 통과
계열 (FACULTY)44 (11×4)각 계열 교수 격파 후 계열 로비에서 구매 (매우 비쌈)
⚠ ULTRA 시련 실패 시 10분 재도전 금지. 기본 시련 실패는 5분.

포션 (5종)

몹에게서 낮은 확률로 드롭. 슬롯 1/2/3 에 자동 배정.

  • HEAL - HP 회복 40
  • MANA - MP 회복 40
  • SWIFT - 이속 +40% 12초
  • FURY - 데미지 +50% 15초
  • GUARD - 무적 3초

5. 축복 (Blessings)

각 층 이동 시 3장의 축복 카드가 나타납니다. 하나를 골라 이번 런 동안 유지되는 강력한 효과를 획득. 38종.

대표 축복

  • BARRAGE - 모든 발사체 2배
  • CHAIN LIGHTNING - 킬 시 인접 적에 번개
  • GLASS CANNON - 데미지 ×3, 최대 HP -50%
  • LAST WARD - HP 1 이하 사망 무효 (60s CD)
  • ORBITAL - 궤도를 도는 오브 2개 소환
  • GREED - RP 드롭 ×2 (대신 최대 HP -10%)
  • PANDEMONIUM - 몹 사망 시 폭발
  • WILDCARD - 다음 층 축복 3개 랜덤 획득
  • ARCANA BLESSING - 모든 스탯 ×1.3
  • IMMORTAL - HP 10 이하로 안 떨어짐 (60s CD)
💡 축복은 로그아웃/재로그인/새 던전 진입 시 초기화. 대신 다음 층 이동 시 새 카드 등장.

6. 영구 성장 (LEGACY 문)

LEGACY 문을 통해 3가지 영구 시스템에 접근:

관록 (LEGACY PILLARS) - 10기둥

RP 로 사는 영구 계정 스탯. 로그 스케일 비용 (레벨 오를수록 다음 비용 30~42% 증가).

  • DAMAGE PILLAR (+1% DMG / lv)
  • VITAL PILLAR (+1% MAX HP / lv)
  • MANA PILLAR (+2% MAX MP / lv)
  • SWIFT PILLAR (-0.5% CD / lv)
  • CRIT / REGEN / SWIFTFOOT / BLOODBIND / BULWARK / FORTUNE

아티팩트 (ARTIFACT) - 30종

매일 5개 로테이션 (오늘 날짜 시드). RP 로 구매 후 3슬롯에 장착.

Tier 1~5. 대표: ARCANA CROWN (DMG ×5, HP ×2), PHOENIX DOWN (자동 부활), ELITE MARKER (엘리트 확률 ×3)

트레잇 (TRAIT) - 20종

7개 카테고리 (ATK/DEF/UTIL/CRIT/ECO/COOP/TRAIN). 5슬롯 자유 스왑.

💡 관록은 로그 스케일이라 아무리 많은 RP 가 있어도 계속 사고 싶어집니다. APEX 티어와 궁합.

7. 커스터마이즈 (STYLE 문)

4가지 외관 요소:

  • ROBE - 12색 (Arcane Purple, Crimson, Emerald, Abyss Blue, Gold, Midnight, Rose, Frost, Inferno, Void, Angel, Prismatic)
  • HAT - 7종 (Classic, Crimson, Green, Golden, Crown, Dark Crown, Prism Crown)
  • STAR - 5종 (모자 위 별 장식)
  • TRAIL - 8종 (걸을 때 남는 궤적: Gold, Arcane, Blood, Frost, Ember, Void, Rainbow)

RP 로 구매. 미리보기 실시간 반영.

8. 시련과 교수

도서관 시련

LIBRARY 문에서 Z 키로 카테고리 선택 → 시련 보스 도전. 클리어 시 MAX/ULTRA 스킬 슬롯 해금.

계열 로비 (PROF 문)

암호 퀘스트를 1회 이상 풀어야 나타나는 파란 문. 진입하면 7-스포크 휠 UI 에서 계열 선택.

교수 22명 + 교장

11개 계열 × 2명 = 22명. 각 계열: 인문/철학/물리/화학/공학/의학/수학/체육/예술/음악/종교. 각 교수는 고유 스킬 패턴, 3페이즈 전투 (등장 → 강화 → 죽음 애니메이션), 격파 시 그 계열 스킬 4종 잠금 해제.

교장 (PRINCIPAL)

11개 계열을 모두 클리어하면 로비 중앙에 나타남. HP 26.25T. 매우 강력.

💡 교수 격파 후 계열 로비 재진입 시 후일담 컷씬이 자동 재생됩니다.

9. 난이도 티어 (C 키)

26 티어 + 1 적응 티어. 티어별로 몹 HP, 데미지, 보상이 다름.

대표 티어:

  • EASY ~ NORMAL - 학습용
  • HARD ~ NIGHTMARE - 진짜 게임 시작
  • HELL ~ TRANSCEND - RP/GPA 대량 획득
  • APEX - 플레이어 공격력에 맞춰 몹 HP 적응. 6e+66 데미지 유저도 재미있게 플레이 가능

10. 랜덤 이벤트

런 이벤트 (던전 방)

각 방 이동 시 20% 확률로 이벤트 방 출현. 전투 대신 대화 + 2~3 선택지. 20종.

대표: 잊힌 제단 (HP 대가), 회복의 샘, 수수께끼 상인 (축복 구매), 저주받은 책, 도박사 주사위, 악마와의 계약, 불사조 깃털

몹 접두 (Affix)

일반 몹의 5% (INFERNO/EXTREME 은 12%) 에 랜덤 접두 능력 부여. 색상 링 + 이름표로 표시.

  • 폭발성 - 사망 시 12발 폭발
  • 재생 - 초당 2% HP 회복
  • 얼음결계 - 히트 시 플레이어 슬로우
  • 그림자 분신 - 사망 시 절반 HP 로 부활 1회
  • 질주자 - 이속 ×1.7
  • 철갑 - HP ×2.5
  • 맹독 - 히트 시 플레이어 독
  • 번개촉수 - 2.5초마다 3발 즉발 번개

아침 이벤트

매일 (state.day) 결정론적 랜덤 12종. 아카데미 상단에 티커 + 관련 문 강조.

대표: 도서관 소리, 아레나 축제, 상인 특가, 안개 (오늘 DR -5%), 축제일 (RP 드롭 +50%), 벽의 낙서

11. 팁

  1. 초반: EASY 티어로 몇 판 → 파이어볼 데미지/CD 특성 위주 → 첫 시련 도전
  2. 중반: MAX 스킬 하나 뽑기 (5분 안 100 kill 정도로 가능) → EXTRA 문 열기
  3. ULTRA 시련: 40초 제한. 미리 DPS 를 확인하고 도전. 실패 시 10분 밴
  4. 암호 문: 시저 암호는 정직하게 알파벳 시프트, 아핀은 곱셈 + 시프트. 매번 위치가 바뀔 수 있음
  5. 축복 선택: 이번 층 몹 종류/HP 를 보고 정하기. HP 폭탄이면 GLASS CANNON, 잡몹 밀치면 ORBITAL
  6. RP 최적화: 관록 GOLD PILLAR + 트레잇 FORTUNE + 아티팩트 MERCHANT PURSE 조합으로 RP 획득량 폭증
  7. APEX 티어: 이미 사기 데미지 인데 지루하면 APEX 로. 6e+66 도 힘든 전투 됨
  8. 훈련장 (TRAIN): 실전 없이 자기 DPS 확인 + RP 획득. 15초마다 자동 평가
  9. 죽으면: 던전 재진입 시 사망 지점에 유품 파우치 (골드 회수). AUTO POUCH 아티팩트로 자동 회수 가능
  10. 계정 저장: 서버 사이드 저장 지원. 다른 기기에서도 같은 계정으로 로그인 가능

추가 시스템

도감 (X 키)

8개 탭: PERKS / SKILLS / DIFFICULTY / TRIALS / VISUALS (투사체 미리보기) / ACHIEVE / DAILY / STORY

업적 (25종) + 일일 도전 (3/일)

업적: 총 킬수, 크리트 히트, 특정 티어 클리어 등. 일일: 매일 3개 랜덤 미션. 완료 시 RP.

스토리 조각 (23편)

플레이하면서 랜덤 획득. 모두 모으면 아카데미의 진실 컷씬 자동 재생.

코업 멀티플레이 (F 로비)

같은 방에 접속한 사람이 던전 문으로 들어가면 5초 안에 참가 가능. 호스트 권한, 몹 HP 동기화.
